## Notes

- "Resized to 1600px" means the file was fetched via the Wikimedia Commons
  thumbnail API at a maximum width of 1600px. Images whose original is larger
  were downscaled; no other image edits (colour, retouching, composition) were
  made.
- CC BY / CC BY-SA images require attribution and, for adaptations, a note that
  changes were made. Attribution is rendered on site; the "Modifications" column
  above records the resize/crop applied.
- `taiyuan.png` is served through `next/image`, which transcodes PNG to an
  optimised format (WebP/AVIF) for browsers that support it.
